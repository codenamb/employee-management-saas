# Employee Management SaaS

A full-stack Employee Management System built with **React**, **Spring Boot**, and **PostgreSQL**. The application allows users to manage employee records through a modern dashboard with CRUD operations, search, analytics, and Excel import/export. An AI-powered employee assistant is currently under development.

---

## 🚀 Features

- Employee CRUD Operations
- Search Employees
- Pagination
- Excel Import & Export
- Interactive Charts
- Responsive UI
- RESTful APIs
- PostgreSQL Database Integration
- Chatbot Assistance

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/codenamb/employee-management-saas.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Database

Create a PostgreSQL database:

```sql
CREATE DATABASE employee_db;
```

Update your PostgreSQL username and password in:

```
backend/src/main/resources/application.properties
```
